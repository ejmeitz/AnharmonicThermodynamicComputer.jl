# AnharmonicThermodynamicComputer.jl

A thermodynamic computer built with anharmonic oscillators and simulated using the SciML ecosystem. The goal is to simulate trajectories on multiple GPUs, use automatic differentiation to optimize on the host until the computer has the desired behavior.


Based on the [paper](https://doi.org/10.1038/s41467-025-67958-0) by Stephen Whitelam and Corneel Casert, "Nonlinear thermodynamic computing out of
equilibrium". Nature Communications, (2025).
